# Calculadora-de-IMC

Este projeto consiste em um site simples de Calculadora de IMC (Índice de Massa Corporal), desenvolvido para praticar conceitos básicos de desenvolvimento web.

O usuário informa seu peso e altura, e o site realiza o cálculo do IMC automaticamente. Após o cálculo, o resultado é apresentado na tela junto com a classificação do IMC, como abaixo do peso, peso normal, sobrepeso ou obesidade.

Tecnologias utilizadas
HTML5
CSS3
JavaScript
Funcionalidades
Entrada de peso e altura
Cálculo automático do IMC
Exibição do valor do IMC
Classificação do resultado
Interface simples e intuitiva
Objetivo

O objetivo do projeto é colocar em prática conhecimentos de HTML, CSS e JavaScript, principalmente a utilização de formulários, estilização de elementos e lógica de programação para realizar cálculos e exibir informações dinamicamente.
